### Hi, I'm Pierre-Louis 👋

AI engineer based in Lyon, France. I build retrieval and agent systems, and the evaluations that decide whether they ship.

**Most recently — AI/ML Engineer intern at NEOFACTO (Feb–Jul 2026).** On ResumAI, a search engine that matches résumés to job descriptions, I owned the retrieval and ranking models end to end:

- Fine-tuned an 8B embedding model and an 8B reranker with LoRA on a single H100: **recall@10 0.636 → 0.803, nDCG 0.812 → 0.909** against the off-the-shelf embedding baseline
- Served the models with vLLM, with Weaviate as the vector store and a LangGraph agent that reformulates recruiter queries
- Tracked experiments and versioned data and models with MLflow, DVC and Weights & Biases
- Wrote the EU AI Act Annex IV technical documentation and the GDPR material, and led the risk assessment

That code is proprietary. Public projects in the same spirit, on technical documentation, are in progress.

**Before ML,** I spent 2022–2025 building software for clients: industrial machine interfaces, an IoT monitoring module, and custom tools for construction firms through my own company.
